# YB-AI 管理器 编译说明

## 前置条件

你需要安装 .NET 8.0 SDK 或更高版本（你已经有 .NET 10.0 了，完美！）：
- 下载地址：https://dotnet.microsoft.com/download/dotnet/8.0

## 编译方法（推荐 - 超小体积！）

在 `ui` 目录下打开命令提示符或 PowerShell，运行：

```cmd
cd ui
dotnet publish -c Release -r win-x64
```

编译完成后，可执行文件在：
`ui\bin\Release\net8.0-windows\win-x64\publish\YB-AI-Manager.exe`

这个版本使用**框架依赖模式**，体积非常小（只有几 MB），Windows 10/11 自带 .NET 8 运行时，直接运行即可！

## 部署

将编译好的 `YB-AI-Manager.exe` 复制到项目根目录（与 `nodejs`、`dist`、`templates` 在同一级目录），然后双击运行即可！

## 目录结构

```
YB-AI/
├── ui/                      # C# 项目源代码
├── nodejs/                  # Node.js 便携版
├── dist/                    # 编译后的 JS 代码
├── templates/               # 模板文件
└── YB-AI-Manager.exe        # 编译后的可执行文件
```
