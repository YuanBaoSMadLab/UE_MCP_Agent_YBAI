# UE5.8 原生 MCP 插件工具集指南

本指南介绍了 Unreal Engine 5.8 原生 MCP 插件提供的主要工具集和功能，帮助 YB-AI 用户更好地利用 AI 助手来操控编辑器。

## 核心概念

### 工具集（Toolsets）
UE5.8 MCP 插件将功能组织为工具集，每个工具集提供一组相关的工具。你需要先加载工具集才能使用其中的工具。

### 元工具（Meta-tools）
有三个特殊的工具用于管理工具集：

1. **`list_toolsets`** - 列出所有可用的工具集
2. **`describe_toolset`** - 获取某个工具集的详细信息
3. **`load_toolset`** - 加载指定的工具集

## 使用流程

### 1. 列出可用工具集
```
请列出 UE5 编辑器中可用的所有 MCP 工具集
```

### 2. 了解工具集详情
```
请详细描述 [工具集名称] 工具集
```

### 3. 加载工具集
```
请加载 [工具集名称] 工具集
```

### 4. 使用工具集中的功能
加载工具集后，就可以使用其中的各种工具了！

## 常用工具集

### SceneTools（场景工具集）
用于场景和 Actor 操作的核心工具集。

#### 主要功能：
- **查找 Actor** - 在场景中搜索特定的 Actor
- **添加到场景** - 从资产库添加内容到场景
- **创建几何体** - 生成基本几何体（立方体、球体、圆柱体等）
- **变换操作** - 移动、旋转、缩放 Actor
- **属性编辑** - 修改 Actor 的属性

#### 使用示例：
```
请在场景中心创建一个 100x100x100 的立方体
```

```
请查找场景中所有名为 "Light" 的光源 Actor
```

### AssetTools（资产管理工具集）
用于管理项目中的资产。

#### 主要功能：
- **浏览资产** - 查看项目中的资产
- **导入资产** - 导入新的资源
- **导出资产** - 导出资源
- **创建资产** - 创建新的资产

### BlueprintTools（蓝图工具集）
用于编辑和操作蓝图。

#### 主要功能：
- **获取图表信息** - 查看蓝图图表
- **列出图表** - 列出蓝图中的所有图表
- **编辑节点** - 添加、修改和连接蓝图节点
- **编译蓝图** - 编译蓝图代码

### 其他可能的工具集
UE5.8 插件可能还提供以下工具集（具体取决于插件版本）：
- **MaterialTools** - 材质编辑器工具
- **AnimationTools** - 动画相关工具
- **SequencerTools** - 关卡序列工具
- **LandscapeTools** - 地形编辑工具
- **AudioTools** - 音频工具

## 已知问题与建议

### 工具调用问题
根据社区报告，UE5.8 预览版中的工具调用可能会导致：
1. HTTP 连接堆积
2. 编辑器挂起
3. 断言失败和崩溃

### 建议使用方式
1. **先使用只读操作** - 先用 list_toolsets、describe_toolset 等验证连接
2. **逐步测试** - 一次只尝试一个操作
3. **及时保存** - 在进行重要操作前保存工作
4. **准备重启** - 如果遇到问题，准备好重启编辑器

### 错误调试
如果遇到问题，请检查：
- UE5 编辑器的输出日志
- 网络连接状态
- MCP 插件是否正确启用和配置

## AI 助手使用技巧

### 给 AI 提供明确的指令
```
好的，请按照以下步骤操作：
1. 首先列出所有可用的工具集
2. 加载 SceneTools 工具集
3. 在坐标 (0, 0, 0) 处创建一个球体
4. 将球体向上移动 200 个单位
```

### 分步骤操作
对于复杂任务，建议让 AI 分步骤完成，每一步确认后再继续。

### 利用上下文
你可以让 AI 先查看场景状态，然后根据当前情况进行操作。
